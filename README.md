# סימולטור עיוורון צבעים

ראו את העולם כפי שאחרים רואים אותו — בתמונה, או דרך מצלמת הטלפון בזמן אמת.

## יכולות

- **מצלמה חיה** — כוונו את הטלפון לסביבה וראו אותה בזמן אמת דרך סוג הראייה שבחרתם. העיבוד רץ על כרטיס המסך (WebGL), עם מעבר אוטומטי לעיבוד במעבד כשאין WebGL. השוואה מפוצלת, החלפת מצלמה קדמית/אחורית, מסך מלא, וצילום פריים להמשך ניתוח.
- **תמונות** — העלאה, גרירה או הדבקה מהלוח; תצוגה מפוצלת עם קו השוואה נגרר, זה לצד זה, או כל הסוגים יחד; הורדת התמונה המסומלצת או תמונת השוואה.
- **חמישה סוגי ראייה** — תקינה, פרוטן, דאוטרן, טריטן ומונוכרומטיות, עם חומרה רציפה (מנומליה חלקית ועד דיכרומטיות מלאה) והמינוח הקליני המתאים.
- **פרטיות** — הכול רץ מקומית בדפדפן. שום תמונה לא נשלחת לשום מקום.
- מצב כהה ובהיר, RTL מלא, נגישות מקלדת וקוראי מסך, ותצוגה מותאמת לנייד.

## דיוק

| סוג | מודל (ברירת מחדל) | הערות |
| --- | --- | --- |
| פרוטן / דאוטרן | Machado, Oliveira & Fernandes 2009 | מדמה הסטה בקונוס, ולכן גם צורות חלקיות. טבלאות המקור משוכפלות מילה במילה מ-colorspacious |
| טריטן | Brettel, Viénot & Mollon 1997 | הפרמטרים של libDaltonLens. מטריצת הטריטן של Machado אינה הקרנה (det ≈ 0.24), ולכן היא לא משמשת כברירת מחדל |
| מונוכרומטיות | בהירות יחסית Rec. 709 | הצורה החלקית היא קירוב |

כל החישובים נעשים באור ליניארי עם פונקציות ההמרה המדויקות של sRGB. אפשר לבחור מודל אחר תחת "הגדרות מתקדמות".

## בדיקות

```bash
npm ci
npx playwright install chromium
npm test            # בדיקת תחביר + בדיקות יחידה + בדיקות קצה לקצה
npm run test:unit   # מנוע הסימולציה בלבד, ללא תלויות
npm start           # שרת מקומי בכתובת http://localhost:8080 (המצלמה עובדת ב-localhost)
```

**בדיקות יחידה** (`tests/unit`):
- השוואה לתמונות הייחוס של DaltonLens: סטייה של יחידה אחת לכל היותר לערוץ, באותה סבילות שבה משתמשת libDaltonLens.
- אינטרפולציית Machado מול וקטורי הבדיקה של colorspacious.
- שלמות הנתונים: שימור הלבן, מטריצות דיכרומטיות בדרגה 2, ו-Brettel כהקרנה אידמפוטנטית.
- מימוש ייחוס עצמאי ב-float64, החזרה מדויקת של sRGB לכל 256 הערכים, נייטרליות של גווני אפור, רציפות תפיסתית (ΔE ב-CIELAB) ושימור ערוץ האלפא.

**בדיקות קצה לקצה** (`tests/e2e`, Chromium אמיתי):
- העלאה דרך שדה הקובץ ושחזור תמונות הייחוס בתוך הדפדפן.
- התאמה בין תצוגת ה-GPU לחישוב במעבד.
- הורדות, מצבי התצוגה וקו ההשוואה (עכבר ומקלדת).
- מצלמה חיה עם מכשיר מדומה, כולל צילום, עצירה ודחיית הרשאה.
- פריסה בנייד ללא גלילה אופקית, ושם נגיש לכל פקד.

הבדיקות רצות אוטומטית ב-GitHub Actions על כל push ו-pull request.
